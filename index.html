1. Conversión de números binarios a código Gray

Definición Matemática:

Sea un número binario de $n$ bits representado como $B = b_1 b_2 \dots b_n$, donde $b_1$ es el bit más significativo. El código Gray correspondiente $G = g_1 g_2 \dots g_n$ se calcula mediante las siguientes ecuaciones:

$$g_1 = b_1$$ $$g_i = b_{i-1} \oplus b_i \quad \text{para } i \geq 2$$

* Donde $\oplus$ representa la operación lógica XOR (O exclusivo): devuelve $0$ si los bits son iguales, y $1$ si son diferentes.

a) 0101

Definimos los bits del número binario: $b_1=0$, $b_2=1$, $b_3=0$, $b_4=1$.

  • $g_1 = b_1 \rightarrow \mathbf{0}$
  • $g_2 = b_1 \oplus b_2 = 0 \oplus 1 \rightarrow \mathbf{1}$
  • $g_3 = b_2 \oplus b_3 = 1 \oplus 0 \rightarrow \mathbf{1}$
  • $g_4 = b_3 \oplus b_4 = 0 \oplus 1 \rightarrow \mathbf{1}$

Resultado en código Gray: 0111

b) 101101

Definimos los bits del número binario: $b_1=1$, $b_2=0$, $b_3=1$, $b_4=1$, $b_5=0$, $b_6=1$.

  • $g_1 = b_1 \rightarrow \mathbf{1}$
  • $g_2 = b_1 \oplus b_2 = 1 \oplus 0 \rightarrow \mathbf{1}$
  • $g_3 = b_2 \oplus b_3 = 0 \oplus 1 \rightarrow \mathbf{1}$
  • $g_4 = b_3 \oplus b_4 = 1 \oplus 1 \rightarrow \mathbf{0}$
  • $g_5 = b_4 \oplus b_5 = 1 \oplus 0 \rightarrow \mathbf{1}$
  • $g_6 = b_5 \oplus b_6 = 0 \oplus 1 \rightarrow \mathbf{1}$

Resultado en código Gray: 111011

2. Expresión de números decimales en códigos BCD y Exceso-3

Para convertir un número decimal $D = d_k d_{k-1} \dots d_0$:

  • Código BCD: Cada dígito decimal $d_i$ se convierte directamente a su representación binaria de 4 bits.
  • Código Exceso-3: A cada dígito decimal $d_i$ se le suma $3$ algebraicamente, y el resultado $(d_i + 3)$ se convierte a su representación binaria de 4 bits.

Número decimal: 1566

Dígito Decimal Conversión BCD (4 bits) Operación Exceso-3 $(d_i + 3)$ Conversión Exceso-3 (4 bits)
1 0001 $1 + 3 = 4$ 0100
5 0101 $5 + 3 = 8$ 1000
6 0110 $6 + 3 = 9$ 1001
6 0110 $6 + 3 = 9$ 1001

Resultado BCD: 0001 0101 0110 0110

Resultado Exceso-3: 0100 1000 1001 1001
